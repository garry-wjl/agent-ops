# Quality Score — 质量评分卡

> 给每个业务模块和架构层打分,让 agent 能识别哪些区域是"高质量参考"、哪些是"待改善地雷"。
> 评分定期更新(建议每个 sprint 结束)。

---

## 评分标准

| 等级 | 含义 | 说明 |
|------|------|------|
| **A** | 高质量参考 | 文档完整、测试充分、无已知问题、可作为新模块的范本 |
| **B** | 合格 | 满足核心要求,但有小幅改进空间 |
| **C** | 待改善 | 有明显技术债,但不影响主流程 |
| **D** | 危险 | 已知 bug 或反模式,agent 不应模仿 |
| **N/A** | 未实现 | 模块/层尚未落地 |

# AgentOps — UI 整体升级 PRD

> 文档日期：2026-06-15 | 版本：v1.0
> 上游输入：用户提出的 UI 升级需求（顶栏 + 空间级导航 + 面包屑）
> 关联 PRD：[工作空间管理 PRD](./2026-06-03-工作空间管理-PRD.md)
> 代码仓库：`rd-agent-fe`（Umi Max + Ant Design Pro + ProLayout）

---

## 1. 背景与目标

### 1.1 为什么要做

当前平台采用 **ProLayout 侧栏布局**（`layout="side"`），LOGO 区和用户信息嵌入在侧栏顶部。随着工作空间功能的引入，"空间切换"也放在侧栏顶部（`WorkspaceSwitcher`），导致侧栏头部区域信息密度过高。

此外，现有布局缺乏**全局顶栏导航**，空间内的新建/编辑页面缺少清晰的面包屑导航路径。

### 1.2 升级目标

| 目标 | 度量 |
| --- | --- |
| 顶栏承载全局导航 | LOGO + 空间切换器 + 面包屑 + 用户信息统一归入顶栏 |
| 平台级/空间级布局一致 | 内外布局结构相同，内容根据上下文变化 |
| 空间内导航更清晰 | 顶栏展示空间切换器 + 面包屑，新建/编辑页面有明确层级路径 |
| 风格与现有风格一致 | 沿用 Ant Design Pro 色彩系统、ProLayout 组件，不做视觉体系重构 |

### 1.3 设计原则

- **改动最小化**：基于 ProLayout 原生能力（`layout="mix"`），不引入新组件库或自定义布局框架
- **风格一致性**：延续现有配色 `#2B52D9`（主色）、`#0F172B`（标题色）、`#F5F7FA`（内容背景）
- **渐进式升级**：仅迁移 LOGO、用户信息、空间切换器到顶栏；侧栏菜单结构、内容区域、路由逻辑全部不变

## 2. 升级范围与决策

### 2.1 当前状态

| 组件 | 当前实现 | 文件 |
| --- | --- | --- |
| 一级门户布局 | ProLayout `layout="side"`，侧栏顶部 LOGO + 2 个菜单项 | `src/layouts/HomeLayout.tsx` |
| 二级工作区布局 | ProLayout `layout="side"`，侧栏顶部 WorkspaceSwitcher | `src/layouts/WorkLayout.tsx` |
| 空间切换器 | 侧栏顶部「首页 › 空间名」面包屑 + 下拉 | `src/components/WorkspaceSwitcher.tsx` |
| 用户信息 | `avatar.tsx` → ProLayout `avatarProps` | `src/layouts/avatar.tsx` |
| 侧栏宽度 | 220px（HomeLayout）/ 224px（WorkLayout） | 同上 |

### 2.2 核心决策

| 决策项 | 选择 | 理由 |
| --- | --- | --- |
| 布局模式 | **顶栏 + 侧栏混合** | 侧栏菜单结构不变，仅把 LOGO/用户信息上移到顶栏 |
| 顶栏方案 | **ProLayout `layout="mix"` 内置顶栏** | 原生支持，改动最小，不与 ProLayout 能力冲突 |
| 平台级顶栏内容 | **LOGO \| 空白 \| 用户信息** | 平台级菜单项少，导航留侧栏；顶栏保持简洁 |
| 空间级顶栏内容 | **LOGO \| 空间切换器 › 面包屑 \| 用户信息** | 顶栏作为空间内全局导航承载 |
| 面包屑粒度 | **功能级** | 如 `Agent 管理 › 新建`，不展示列表页等中间层级 |
| 侧栏行为 | **保持不变** | 菜单分组、宽度、折叠逻辑全部沿用 |

### 2.3 范围

**本期做**

- ✅ 顶栏组件：承载 LOGO、空间切换器 + 面包屑、用户信息
- ✅ 平台级（空间外）布局：顶栏 + 侧栏 + 内容，顶栏只放 LOGO + 用户信息
- ✅ 空间级（空间内）布局：顶栏 + 侧栏 + 内容，顶栏放 LOGO + 空间切换器 + 面包屑 + 用户信息
- ✅ 空间内新建/编辑页面：功能级面包屑导航
- ✅ 统一风格：沿用 Ant Design Pro 色彩、ProLayout 组件

**本期不做**

- ❌ 侧栏菜单结构调整（分组、图标、路由全部不变）
- ❌ 内容区域样式重构（页面组件、表格、表单全部不变）
- ❌ 视觉体系重构（颜色、字体、间距、圆角全部不变）
- ❌ 响应式/移动端适配
- ❌ 暗黑模式

## 3. 界面布局规范

### 3.1 总体布局结构

两种场景采用**相同布局结构**，顶栏内容不同：

```
┌──────────────────────────────────────────────┐
│              顶栏 HeaderBar                   │
│  LOGO  │  [空间切换器 › 面包屑]  │  用户信息    │
├────────┬─────────────────────────────────────┤
│        │                                      │
│  侧栏   │           内容区                     │
│  Menu  │                                      │
│        │                                      │
└────────┴──────────────────────────────────────┘
```

### 3.2 平台级（空间外）顶栏

**场景**：用户登录后到达的一级门户，包含「工作台」、「工作空间」、「空间管理」页面

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 左侧 | 🛰️ LOGO + "AgentOps" 品牌名 | 点击跳转 `/workbench` |
| 中间 | **空白** | 不展示菜单、面包屑 |
| 右侧 | 用户头像 + 退出 | 沿用现有 `avatar.tsx` 的 `buildAvatarProps` |

**侧栏**：显示「工作台」、「工作空间」两个菜单项（与当前 HomeLayout 一致）

### 3.3 空间级（空间内）顶栏

**场景**：用户从工作空间列表进入某个空间后，到达二级工作区

| 区域 | 内容 | 说明 |
| --- | --- | --- |
| 左侧 | 🛰️ LOGO + "AgentOps" 品牌名 | 点击跳转一级门户 `/workbench`（退出当前空间） |
| 中间 | **空间切换器 + 面包屑** | 左侧为空间切换下拉（含返回工作空间），右侧为当前页面包屑，用分隔符 `›` 连接 |
| 右侧 | 用户头像 + 退出 | 与平台级一致 |

**侧栏**：显示分组菜单（Agent与沙箱、模型与工具、调试与评测），与当前 WorkLayout 一致

### 3.4 空间内面包屑规范

| 页面类型 | 面包屑格式 | 示例 |
| --- | --- | --- |
| 列表页 | `模块名` | `Agent 管理` |
| 新建页 | `模块名 › 新建` | `Agent 管理 › 新建` |
| 编辑/详情页 | `模块名 › 实体名称` | `Agent 管理 › 客服助手 Agent` |
| 子功能页 | `模块名 › 子功能名` | `Skill 管理 › 版本历史` |

面包屑在顶栏中间区域，位于空间切换器右侧，用 `›` 分隔。

## 4. 交互规范

### 4.1 空间切换器交互

| 操作 | 行为 |
| --- | --- |
| 点击空间名称 | 展开下拉，展示"当前空间"标题和空间列表 |
| 点击空间列表项 | 切换到该空间，URL 参数 `?ws=` 同步更新，当前页内容重载 |
| 点击「返回工作空间」 | 退出一级门户 `/workbench`，回到空间选择页 |
| 点击顶栏 LOGO | 同「返回工作空间」 |

### 4.2 顶栏点击行为

| 元素 | 点击行为 |
| --- | --- |
| LOGO 区域 | 平台级 → 跳转到 `/workbench`；空间级 → 退出一级门户 |
| 面包屑中的模块名 | 跳转到该模块列表页 |
| 用户头像 | 保持现有下拉行为（无额外菜单，仅退出） |

### 4.3 面包屑生成规则

面包屑由路由配置自动生成。每个页面在 `routes.ts` 中声明 `name` 属性，页面组件中可通过 `useRouteMatch` 或路由 meta 获取当前模块名。

新建/编辑页的面包屑逻辑：

- **新建**：固定追加 `› 新建`
- **编辑/详情**：从页面数据中获取实体名称（如 `agent.name`），追加到面包屑
- 面包屑最后一项为非可点击文本

## 5. 技术实现方案

### 5.1 ProLayout 配置变更

| 属性 | 当前值 | 升级后 |
| --- | --- | --- |
| `layout` | `"side"` | `"mix"` |
| `headerHeight` | 默认 | `48px`（统一高度） |
| `siderWidth` | `220` / `224` | 统一 `220px` |
| `fixedHeader` | `true` | `true` |
| `navTheme` | 默认 | `"light"`（白色顶栏） |
| `menuHeaderRender` | 自定义 LOGO + 切换器 | `false`（顶栏接管） |

### 5.2 布局文件变更

| 文件 | 变更内容 |
| --- | --- |
| `src/layouts/HomeLayout.tsx` | 改为 `layout="mix"`；移除 `menuHeaderRender`；LOGO 和 avatar 由顶栏渲染 |
| `src/layouts/WorkLayout.tsx` | 改为 `layout="mix"`；移除 `menuHeaderRender`；顶栏中间区域挂载 `HeaderNav` 组件（空间切换器 + 面包屑） |
| `src/components/WorkspaceSwitcher.tsx` | 从侧栏顶部组件改造为顶栏中间区域组件；收起侧栏时隐藏 |
| **新增** `src/components/HeaderNav.tsx` | 顶栏中间区域：空间切换器 + 面包屑组合组件 |
| **新增** `src/components/HeaderBreadcrumb.tsx` | 面包屑组件，从路由配置生成 |
| **新增** `src/components/HeaderLogo.tsx` | 顶栏左侧 LOGO 组件（统一 HomeLayout / WorkLayout 样式） |

### 5.3 样式变更

| 变更项 | 说明 |
| --- | --- |
| 顶栏背景 | `#ffffff`（与 ProLayout 默认一致） |
| 顶栏边框 | `border-bottom: 1px solid #f0f0f0`（ProLayout 内置） |
| 顶栏高度 | `48px`（紧凑型，不超过内容密度） |
| 侧栏背景 | 空间内保持 `#ffffff`（与当前 WorkLayout 一致） |
| 内容背景 | 平台级 `#F5F7FA`，空间级 `#ffffff`（不变） |

### 5.4 面包屑数据来源

面包屑由路由配置的 `name` 字段驱动。当前路由结构已包含 `name`：

```
Agent 管理 → name: "Agent 管理"
Skill 管理 → name: "Skill 管理"
...
```

新建/编辑页的面包屑名称由页面组件通过 `useParams` 获取实体名称后注入。

## 7. 风险与缓解

| 风险 | 缓解措施 |
| --- | --- |
| ProLayout `layout="mix"` 与 `menu={{ type: "group" }}` 兼容性问题 | 提前在测试分支验证 ProLayout 的 mix 模式对分组菜单的支持 |
| 空间级顶栏面包屑在收起侧栏时显示异常 | 侧栏宽度变化不影响顶栏；顶栏是独立层级 |
| 切换空间时顶栏面包屑不刷新 | 面包屑 key 绑定 `currentWorkspaceNum`，切换空间时整块重挂载 |

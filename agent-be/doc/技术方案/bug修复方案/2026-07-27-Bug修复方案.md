## Bug：沙箱工具 execute_command / execute_python 拿不到命令输出

| 字段 | 值 |
|------|-----|
| 模块 | Agent 运行时 - 沙箱工具（SandboxTool） |
| BUG 分类 | 功能-功能错误 |
| 引入阶段 | 编码缺陷（结果字段读取错误） |
| 严重程度 | 严重 A（工具能力实质不可用） |
| 复现概率 | Always |

### 现象

Agent 调用内置沙箱工具 `execute_command`（执行 shell 命令）与 `execute_python`（执行 Python 代码）时，工具**能正常执行**，但返回给 Agent 的结果里**只有一行退出码**（如 `\n[exitCode] 0`），拿不到命令 / 脚本真正打印的 stdout / stderr 内容。表现为"命令跑了，但看不到输出"。

同一批工具中 `read_sandbox_file`、`write_sandbox_file`、`format_json`、FunctionCall 类工具均正常——它们不经过沙箱 `Execution` 结果模型。

### 原因分析

**结论：后端 Bug（`SandboxTool.renderExecution` 读错结果字段）**

定位路径：反编译沙箱 SDK `com.alibaba.opensandbox:sandbox:1.0.11`，确认 `Execution` 的输出由 `ExecutionEventDispatcher` 按 SSE 事件类型分流到两套字段：

| SSE 事件 | 写入字段 | 含义 |
|---|---|---|
| `stdout` | `execution.getLogs().getStdout()` | **命令/脚本标准输出** |
| `stderr` | `execution.getLogs().getStderr()` | **标准错误输出** |
| `result` | `execution.getResult()` | 仅 Jupyter 式"最后一个表达式的富返回值" |
| `error` | `execution.getError()` | 仅异常事件 |
| `execution_complete` | `exitCode` / `complete` | 退出码 |

关键点：`getResult()` 装的是 Jupyter kernel 里表达式求值的**富返回值**，而不是命令打印到 stdout 的文本。

而两个工具都走 `commands().runInSession(...)` 执行 bash 命令（`execute_python` 也是先写临时 `.py` 文件、再当成 shell 命令 `python3 /tmp/xxx.py` 跑）。这种执行方式所有输出都通过 **`stdout` 事件 → `logs.stdout`** 回来，`result` 基本恒为空。

原 `renderExecution` 只读了 `execution.getResult()` / `getError()` / `getExitCode()`，**从未读取 `execution.getLogs()`**，于是 stdout 段恒为空，Agent 只拿到一行 exitCode。

> 注：问题**不在** reactive 返回类型（三个工具都返回 `Mono<ToolResultBlock>`，其余正常），而在结果字段读取。

### 修改方案

| 端 | 改动内容 |
|----|---------|
| **后端** | 重写 `SandboxTool.renderExecution`：优先读取 `execution.getLogs().getStdout()/getStderr()`（元素 `OutputMessage`，取 `getText()`）作为主输出；`result` 降级为补充富结果段落（`[result]`）；stderr 以 `[stderr]`、error 以 `[error]` 段落输出，末尾保留 `[exitCode]`。抽出 `joinMessages` / `appendSection` 辅助方法，对 null logs/result 做防御。 |

**渲染后输出格式（示意）：**

```
<stdout 文本>
[stderr] <stderr 文本>       # 有才输出
[result] <富返回值>           # Jupyter 富结果，有才输出
[error] <name>: <value>       # 有才输出
[exitCode] 0
```

### 影响范围

- 仅后端 `rd-agent-be`，单文件 `SandboxTool.java`（application 层），无接口 / DB / 前端改动。
- 行为变化：`execute_command` / `execute_python` 的返回值从"仅 exitCode"变为"完整 stdout/stderr + exitCode"，对 Agent 只增不减，向后兼容。

### 验证

- 新增单元测试 `SandboxToolRenderExecutionTest`（7 用例）：覆盖 stdout / stderr / 二者并存 / 富结果补充 / error 段 / exitCode 为 null / 无输出，全部通过。
- application 模块 `mvn test` 全量绿（无回归）。

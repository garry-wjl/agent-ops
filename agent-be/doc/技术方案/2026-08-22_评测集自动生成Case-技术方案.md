# 2026-08-22_评测集自动生成Case-技术方案

## 1. 目标与范围

**目标**：在评测集详情「行数据」右上角提供「自动生成评测 Case」——用户选择平台内生成器 Agent（须可选已发布/可调试版本），平台注入默认用户提示词（含评测集定义；AGENT 型另含被测 Agent 定义），可选指定条数与自定义说明（追加/覆盖），异步执行；解析符合 Schema 的 Case 写入草稿；支持历史与失败重试；落审计。

**共识摘要**
- 生成器：已发布/可调试；默认在线版，可选手选版本
- CUSTOM 评测集：提示词省略被测 Agent 段
- 输出须符合 Schema；不合格行跳过
- 仅写草稿；条数未指定则提示「自行决定合理数量」；指定时平台硬上限 **50**
- 异步任务 + 进度轮询；完成后刷新行列表
- 弹窗可选：追加 / 先清空草稿再写入
- 权限：`evaluation:dataset:update`
- 自定义说明：追加或覆盖默认提示词
- 部署架构不变
- 任务表即审计主账本 + 结构化日志；含历史与重试

**不在范围**：改写已发布版本行；跨工作空间生成器；流式前端展示 Agent token。

## 2. 架构设计

### 2.1 应用架构

| 层 | 领域 | 包 | 职责 |
|----|------|-----|------|
| client | evaluation.dataset | `...client.evaluation.dataset` | StartCaseGenParam / Job VO / PageQuery |
| domain | evaluation | `...domain.evaluation.gateway` | EvalNumGateway 增加 ECG 编号 |
| infra | evaluation.dataset | entity/mapper | `eval_dataset_case_gen_job` |
| application | evaluation.dataset | casegen | PromptBuilder / ResultParser / Worker / Command·Query |
| adapter | evaluation.dataset | command/query Controller | HTTP 入口 |

调用：`CommandController.startCaseGen` → 落库 PENDING → `@Async evaluationExecutor` Worker → `AgentInvokeService.invokeStream` → 解析 → `EvalDataset.appendDraftRow` / `replaceDraftRows` → 更新 Job。

### 2.2 部署架构

部署架构不变，无新增应用/前端部署实例，复用现有部署架构。

## 3. Facade

本次无 Facade 层变更。

## 4. 领域要点

- Job 状态：`PENDING` → `RUNNING` → `FINISHED` | `FAILED`（可 `retry` 派生新 Job 或同 Job 重置为 PENDING）
- 同一 `dataset_num` 同时仅允许 1 个 `PENDING/RUNNING` Job
- 编号前缀：`ECG`

## 5. 数据与接口

### 5.1 表 `eval_dataset_case_gen_job`（Flyway V42）

字段含：num、workspace_num、dataset_num、generator_agent_num/version、target_count、clear_draft、instruction_mode(APPEND|OVERRIDE)、user_instruction、status、progress_pct、progress_message、parsed/written/skipped_count、error_message、raw_output、prompt_snapshot、retry_of_num、create_no/update_no、时间戳。

### 5.2 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/evaluation/dataset/command/startCaseGen` | 创建并异步启动 |
| POST | `/api/v1/evaluation/dataset/command/retryCaseGen` | 失败 Job 重试（新 Job 或重置） |
| POST | `/api/v1/evaluation/dataset/query/caseGenJobDetail` | 进度详情 |
| POST | `/api/v1/evaluation/dataset/query/pageCaseGenJobs` | 某评测集历史 |

权限：`evaluation:dataset:update`（读历史同 update，详情页已有该权限门槛）。

## 6. 提示词与解析

- 平台默认模板强制要求输出 **JSON 数组**，元素为符合 schema 的对象
- `APPEND`：默认模板 + 用户说明；`OVERRIDE`：用户说明为主，仍追加不可省略的 Schema/输出格式约束段
- 解析：优先 JSON 数组；否则 JSONL；再否则从 markdown code fence 提取；单行校验失败则 skip

## 7. 前端

- Detail 行数据区右上角按钮「自动生成评测 Case」
- Modal：生成器 Agent、版本、条数（可选）、清空策略、说明模式、自定义说明
- 提交后展示进度条/状态；轮询 detail；FINISHED 刷新行列表；历史抽屉可重试

## 1. 一句话总结

在 rd-agent-be `infra/common/client/terra/` 下新增一个 Spring Bean 工具类 **`OssClient`**，封装 Terra 网关「申请上传凭证 / 获取访问链接 / 重命名 / 删除 / 元数据分页」5 类调用；**前端拿凭证直传深圳混合云 OSS**，后端只签发 STS、产 URL 和**轮询确认上传完成**，不接 Cloudbus 回调。

---

## 2. 接入决策摘要

| 维度 | 决策 | 理由 |
|---|---|---|
| **区域 / 节点** | 内网混合云 `cn`（`terra-upload-cn.garrycorp.com`） | 与 rd-agent-be RDS/Redis 同在深圳 cn-shenzhen；底层落 `oss-cn-shenzhen` |
| **上传模式** | 前端直传 OSS（STS 凭证 + putObject / multipartUpload） | 不占后端带宽；最大 48.8 TB；客户端体验最佳 |
| **回调策略** | **不接 Cloudbus**，前端上传完成后由后端轮询 `/api/file-meta/page` 的 `state` 字段 | 业务范围小，避免引入消息网关依赖；后续可平滑切换到 Cloudbus（见 §13） |
| **后端封装** | 单一 Spring Bean `OssClient`，参照 `GcacClient` 模板 | 与现有 `infra/common/client/gcac/` 同模式，复用 `Hutool HttpRequest` 工具栈 |
| **HTTP 出口** | Hutool `cn.hutool.http.HttpRequest` | rd-agent-be 已全量退出 OkHttp，统一到 Hutool（见 OkHttp 退出盘点） |
| **JSON** | fastjson2 | 与 `GcacClient` 一致 |
| **签名** | 走**服务网关代理免签**优先；fallback `timestamp + sign` 直连（HMAC-SHA256） | 网关代签是 garry 内部首选；签名算法 Terra 文档未公开，需向 Terra 团队确认（见 §12） |

## 3. 背景与适用场景

rd-agent-be 当前及未来会出现的文件场景：

1. Agent 头像 / 封面图（小文件，多写）
2. Skill 发布产物 / Manifest 附件
3. Agent 调试台用户上传的附件（聊天附件 + 评测样本）
4. Agent 知识库的文档（PDF / Word / 文本）

共同特征：

- 走前端直传；后端只签凭证、给下载/预览 URL、做生命周期管理（重命名 / 删除 / 查询）。
- 不需要后端持有文件流（避免内存峰值 + 节省 K8s pod 带宽）。

## 4. Terra 核心概念（最小集）

| 概念 | 含义 | rd-agent-be 取值（待申请） |
|---|---|---|
| `app_id` | Terra 应用 ID，与 servicewall 应用 ID 不一定一致 | `rd-agent-be`（待申请） |
| `bucket_name` | Terra 资源桶，区分公开/私有/私密三种 | 初始申请：`rd-agent-be-public`（公开）+ `rd-agent-be-private`（私密） |
| `file_id` | Terra 全局唯一文件 ID，业务方需持久化 | 由 `/upload/sts_init` 返回 |
| `endpoint_type` | `PUBLIC` 走公网域名；`INTERNAL` 走内网；`PROXY` 走 ECS 代理 | rd-agent-be 默认 `PUBLIC`（前端用户在公司内网/外网都需访问） |

**文件名规则**（必须前后端共同校验，避免 Terra `-15` 错误码）：

- 每个路径段 ≤ 128 字符
- 完整路径 ≤ 157 字符
- 禁字符：`& = ; : + , ? \ { ^ } % ` ] " ' > [ ~ < # | /` + 空格
- 路径不能以 `/` 开头/结尾，不能包含连续 `//`

## 5. 整体时序

```
┌──────────┐      ① POST /admin/api/v1/files/upload-token        ┌─────────────┐
│ rd-agent-│ ───────────────────────────────────────────────────▶ │ rd-agent-be │
│   -fe    │                                                      │  (OssClient)│
└──────────┘      ② 返回 STS 凭证 + objectKey + fileId            └─────┬───────┘
     │  ◀─────────────────────────────────────────────────────────────  │
     │                                                                  │
     │            ③ putObject / multipartUpload（前端 OSS SDK）         │ POST /upload/sts_init
     │  ─────────────────────────────────▶  ┌────────────────────────┐  │ + 签名 / 网关代签
     │                                       │  阿里云 OSS            │  │
     │  ◀─────────────────────────────────  │  oss-cn-shenzhen       │  │
     │            ④ 上传成功                 └────────────────────────┘  │
     │                                                                  │
     │            ⑤ POST /admin/api/v1/files/{fileId}/confirm           │
     │ ───────────────────────────────────────────────────────────────▶ │
     │                                                                  │ 轮询 /api/file-meta/page
     │                                                                  │ 直到 state ∈ {10, 20}
     │  ◀─────────────────────────────────────────────────────────────  │
     │            ⑥ 返回 fileId / 下载 URL                              │
     │                                                                  │
     │            ⑦ 后续：取下载链接 / 预览 / 删除                       │
     │ ───────────────────────────────────────────────────────────────▶ │ POST /get/v3/url
     │                                                                  │ POST /file/delete_dir_or_file
     │                                                                  │
     └──────────────────────────────────────────────────────────────────┘
```

状态机简化：

- 前端上传完成 → 后端**轮询** `/api/file-meta/page` 直至 `state ≥ 10`（**10**=已上传 / **20**=已发消息）。
- `state=11` / `state=21` 视为上传失败，返回业务错误。

## 6. 在 rd-agent-be 中的落点

### 6.1 包结构（参照 `GcacClient` 模板）

```
rd-agent-be-infra/src/main/java/ink/garry/rd/agent/ws/infra/common/client/terra/
├── OssClient.java                    # Spring @Component 主类
├── TerraProperties.java              # @ConfigurationProperties("terra")
├── TerraException.java               # 业务异常,携带 code + invokeId + message
├── dto/                              # Terra 网关返回的 DTO
│   ├── StsCredentialDTO.java
│   ├── FileAccessUrlDTO.java
│   ├── FileMetaDTO.java
│   └── FilePageDTO.java
└── param/                            # OssClient 公开方法的入参(Builder)
    ├── StsInitParam.java
    ├── FileUrlParam.java
    ├── FileRenameParam.java
    ├── FileDeleteParam.java
    └── FileMetaPageParam.java
```

**为什么不抽 facade Gateway 接口** — rd-agent-be 在 2026-05-27 已删 `GcacGateway` 抽象，application 层直接注入 `GcacClient`（理由：单一实现 + 无 mock 需求 = 抽象冗余）。`OssClient` 同样属于"对外 HTTP 客户端"范畴，遵循同样的取舍。

### 6.2 配置类 `TerraProperties`

```java
package ink.garry.rd.agent.ws.infra.common.client.terra;

import lombok.Data;
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.stereotype.Component;

/**
 * Terra 文件存储接入配置。
 * <p>
 * 区分两种调用路径:
 * <ul>
 *   <li><b>网关代理</b>(推荐):{@link #gatewayBaseUrl} 指向 servicewall,
 *       由网关用 rd-agent-be 自身 app 身份对 Terra 免签;此时
 *       {@link #appSecret} 可留空。</li>
 *   <li><b>直连 Terra 域名</b>(fallback):{@link #directBaseUrl} 指向
 *       {@code terra-upload-cn.garrycorp.com},需要 {@link #appSecret} 做 HMAC 签名。</li>
 * </ul>
 *
 * <p>{@link #appSecret} 不允许写进 application.yml,必须从 Apollo / 启动参数注入。
 */
@Data
@Component
@ConfigurationProperties(prefix = "terra")
public class TerraProperties {

    /** Terra appId,与 Terra 管理后台申请的应用 ID 一致。 */
    private String appId;

    /** Terra 资源桶名(默认桶);多桶场景调用方在 Param 里覆盖。 */
    private String defaultBucket;

    /** 网关代理 base URL,如 https://servicewall-cn.garrycorp.com 。 */
    private String gatewayBaseUrl;

    /** 直连 Terra 域名 base URL,如 https://terra-upload-cn.garrycorp.com 。 */
    private String directBaseUrl;

    /** Terra app 密钥,直连模式下用于 HMAC-SHA256 签名;网关代理模式可空。 */
    private String appSecret;

    /** 调用模式:GATEWAY / DIRECT。默认 GATEWAY。 */
    private CallMode callMode = CallMode.GATEWAY;

    /** HTTP 连接超时(ms)。默认 5000。 */
    private int connectTimeoutMs = 5000;

    /** HTTP 读超时(ms)。默认 30000(get URL 接口较慢)。 */
    private int readTimeoutMs = 30000;

    /** 轮询确认上传完成的间隔(ms)。默认 1000。 */
    private long pollIntervalMs = 1000L;

    /** 轮询最长等待(ms)。默认 60000(1 分钟)。 */
    private long pollMaxWaitMs = 60_000L;

    /** 调用模式枚举。 */
    public enum CallMode {
        /** 走 servicewall 网关代签(推荐)。 */
        GATEWAY,
        /** 直连 Terra 域名,本地签名。 */
        DIRECT
    }
}
```

对应 `application-dev.yml`：

```yaml
terra:
  app-id: rd-agent-be                                    # 待 Terra 申请
  default-bucket: rd-agent-be-public                     # 待 Terra 申请
  gateway-base-url: https://servicewall-cn.garrycorp.com   # 待 ops 确认
  direct-base-url: https://terra-upload-cn.garrycorp.com
  app-secret: ${TERRA_APP_SECRET:}                       # Apollo / 启动参数注入
  call-mode: GATEWAY
  connect-timeout-ms: 5000
  read-timeout-ms: 30000
  poll-interval-ms: 1000
  poll-max-wait-ms: 60000
```

### 6.3 主类 `OssClient`

```java
package ink.garry.rd.agent.ws.infra.common.client.terra;

import cn.hutool.crypto.SecureUtil;
import cn.hutool.crypto.digest.HMac;
import cn.hutool.crypto.digest.HmacAlgorithm;
import cn.hutool.http.HttpException;
import cn.hutool.http.HttpRequest;
import cn.hutool.http.HttpResponse;
import cn.hutool.http.HttpUtil;
import com.alibaba.fastjson2.JSON;
import com.alibaba.fastjson2.JSONObject;
import ink.garry.rd.agent.ws.infra.common.client.terra.dto.FileAccessUrlDTO;
import ink.garry.rd.agent.ws.infra.common.client.terra.dto.FileMetaDTO;
import ink.garry.rd.agent.ws.infra.common.client.terra.dto.FilePageDTO;
import ink.garry.rd.agent.ws.infra.common.client.terra.dto.StsCredentialDTO;
import ink.garry.rd.agent.ws.infra.common.client.terra.param.FileDeleteParam;
import ink.garry.rd.agent.ws.infra.common.client.terra.param.FileMetaPageParam;
import ink.garry.rd.agent.ws.infra.common.client.terra.param.FileRenameParam;
import ink.garry.rd.agent.ws.infra.common.client.terra.param.FileUrlParam;
import ink.garry.rd.agent.ws.infra.common.client.terra.param.StsInitParam;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

import java.nio.charset.StandardCharsets;
import java.time.Duration;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.TreeMap;

/**
 * Terra 文件存储底层 HTTP 客户端 — Hutool {@link HttpRequest} + fastjson2 实现。
 * <p>
 * infra/common/client 层定义:只负责对 Terra 网关 HTTP 端点的低层调用与
 * 错误码到 {@link TerraException} 的转换;不承担权限校验、审计、文件元数据持久化
 * 等业务编排(那些归 application 层)。
 *
 * <h3>覆盖端点</h3>
 * <ul>
 *   <li>{@code POST /upload/sts_init}    — 申请上传凭证(STS / Token)</li>
 *   <li>{@code POST /get/v3/url}         — 获取源地址 + 预览地址(支持 WPS / Aspose)</li>
 *   <li>{@code POST /file/rename_dir_or_file} — 重命名文件 / 文件夹</li>
 *   <li>{@code POST /file/delete_dir_or_file} — 删除文件 / 文件夹</li>
 *   <li>{@code GET  /api/file-meta/page} — 分页查询文件元数据(轮询用)</li>
 * </ul>
 *
 * <h3>调用模式</h3>
 * <ul>
 *   <li>{@link TerraProperties.CallMode#GATEWAY}:走 servicewall 网关代签,免本地签名。</li>
 *   <li>{@link TerraProperties.CallMode#DIRECT}:直连 Terra 域名,本地按 HMAC-SHA256
 *       做签名(算法见 {@link #sign})。<b>注意:签名算法 Terra 文档未公开,当前为占位,
 *       上线前必须向 Terra 团队确认。</b></li>
 * </ul>
 *
 * <h3>错误码契约</h3>
 * Terra 返回包统一为 {@code {code, message, invokeId, result}};{@code code != 0}
 * 时本类抛 {@link TerraException},业务调用方按 code 决定回显或重试。
 *
 * @see TerraProperties
 * @see TerraException
 */
@Slf4j
@Component
public class OssClient {

    private final TerraProperties props;

    public OssClient(TerraProperties props) {
        this.props = props;
    }

    // ====================== 上传凭证 ======================

    /**
     * 申请上传凭证。前端拿到 {@link StsCredentialDTO} 后,根据 {@code cloudName}
     * 选择 OSS / S3 / 内网 SDK 直传。
     *
     * @param param 业务入参,至少包含 {@code fileName}
     * @return STS 凭证 + objectKey + fileId,业务方必须持久化 {@code fileId}
     * @throws TerraException Terra 返回 {@code code != 0},包括 {@code -10/-14/-15}
     */
    public StsCredentialDTO requestStsCredential(StsInitParam param) {
        Map<String, Object> form = new LinkedHashMap<>();
        form.put("app_id",        defaultIfBlank(param.getAppId(), props.getAppId()));
        form.put("bucket_name",   defaultIfBlank(param.getBucketName(), props.getDefaultBucket()));
        form.put("file_name",     param.getFileName());
        if (param.getFileMd5() != null) form.put("file_md5", param.getFileMd5());
        if (param.getOverwrite() != null) form.put("overwrite", param.getOverwrite() ? "1" : "0");
        if (param.getEndpointType() != null) form.put("endpoint_type", param.getEndpointType());

        JSONObject result = postForm("/upload/sts_init", form, "terra_sts_init");
        return result.to(StsCredentialDTO.class);
    }

    // ====================== 访问链接 ======================

    /**
     * 取文件访问链接 V3。返回包含源地址 + 预览地址(WPS 优先,fallback Aspose)。
     * 私密文件需要客户端按 {@code headers} 附带头部访问 {@code url}。
     */
    public FileAccessUrlDTO getFileUrlV3(FileUrlParam param) {
        Map<String, Object> form = new LinkedHashMap<>();
        form.put("app_id",      defaultIfBlank(param.getAppId(), props.getAppId()));
        form.put("bucket_name", defaultIfBlank(param.getBucketName(), props.getDefaultBucket()));
        form.put("file_id",     param.getFileId());
        if (param.getUrlExpire() != null) form.put("url_expire", param.getUrlExpire());
        if (param.getOssProcess() != null) form.put("oss_process", param.getOssProcess());
        if (param.getWatermarkJson() != null) form.put("watermark", param.getWatermarkJson());

        JSONObject result = postForm("/get/v3/url", form, "terra_get_url_v3");
        return result.to(FileAccessUrlDTO.class);
    }

    // ====================== 重命名 / 删除 ======================

    /** 重命名文件或目录;{@code newName} 不带路径。 */
    public FileMetaDTO renameFileOrDir(FileRenameParam param) {
        Map<String, Object> form = new LinkedHashMap<>();
        form.put("app_id",          defaultIfBlank(param.getAppId(), props.getAppId()));
        form.put("bucket_name",     defaultIfBlank(param.getBucketName(), props.getDefaultBucket()));
        form.put("dir_or_file_id",  param.getDirOrFileId());
        form.put("new_name",        param.getNewName());
        JSONObject result = postForm("/file/rename_dir_or_file", form, "terra_rename");
        return result.to(FileMetaDTO.class);
    }

    /** 按 fileId 或路径(配 {@code isPath=true})删除。 */
    public void deleteFileOrDir(FileDeleteParam param) {
        Map<String, Object> form = new LinkedHashMap<>();
        form.put("app_id",         defaultIfBlank(param.getAppId(), props.getAppId()));
        form.put("bucket_name",    defaultIfBlank(param.getBucketName(), props.getDefaultBucket()));
        form.put("dir_or_file_id", param.getDirOrFileId());
        if (Boolean.TRUE.equals(param.getIsPath())) form.put("is_path", "true");
        postForm("/file/delete_dir_or_file", form, "terra_delete");
    }

    // ====================== 元信息分页(轮询用) ======================

    /** 分页查询文件元数据。轮询确认上传完成的底层调用。 */
    public FilePageDTO pageFileMeta(FileMetaPageParam param) {
        Map<String, Object> query = new LinkedHashMap<>();
        query.put("appId",       defaultIfBlank(param.getAppId(), props.getAppId()));
        query.put("bucketName",  defaultIfBlank(param.getBucketName(), props.getDefaultBucket()));
        if (param.getFileId() != null)         query.put("fileId", param.getFileId());
        if (param.getStartTimestamp() != null) query.put("startTimestamp", param.getStartTimestamp());
        if (param.getEndTimestamp() != null)   query.put("endTimestamp", param.getEndTimestamp());
        if (param.getDeleted() != null)        query.put("deleted", param.getDeleted());
        query.put("currentPage", param.getCurrentPage());
        query.put("pageSize",    param.getPageSize());

        String path = "/api/file-meta/page";
        String url = HttpUtil.urlWithForm(baseUrl() + path, query, StandardCharsets.UTF_8, false);
        HttpRequest request = HttpRequest.get(url);
        String body = exec(request, "terra_file_meta_page");
        return parseEnvelope(body, "terra_file_meta_page").to(FilePageDTO.class);
    }

    // ====================== 便利方法:轮询等待上传完成 ======================

    /**
     * 轮询 {@link #pageFileMeta} 直到 {@code state ≥ 10} 或超时。
     * <p>
     * state 语义:0 初始化 / 10 已上传 / 11 上传失败 / 20 已发消息 / 21 发消息失败。
     * 业务一般在 {@code state ∈ {10, 20}} 时认定上传成功。
     *
     * @return 成功时返回最新 {@link FileMetaDTO};失败抛 {@link TerraException}
     * @throws TerraException 上传失败({@code state ∈ {11, 21}})或超时
     */
    public FileMetaDTO waitForUploadComplete(String appId, String bucketName, String fileId,
                                             Duration timeout) {
        long deadline = System.currentTimeMillis() + timeout.toMillis();
        long interval = props.getPollIntervalMs();
        while (System.currentTimeMillis() < deadline) {
            FilePageDTO page = pageFileMeta(FileMetaPageParam.builder()
                    .appId(appId).bucketName(bucketName).fileId(fileId)
                    .currentPage(1L).pageSize(1L).build());
            if (page.getResult() != null && !page.getResult().isEmpty()) {
                FileMetaDTO meta = page.getResult().get(0);
                Integer state = meta.getState();
                if (state != null && state >= 10) {
                    if (state == 11 || state == 21) {
                        throw new TerraException("terra_upload_failed",
                                -2, "upload state=" + state, null);
                    }
                    return meta;
                }
            }
            sleep(interval);
        }
        throw new TerraException("terra_poll_timeout", -2,
                "wait upload timeout " + timeout, null);
    }

    // ====================== 私有工具 ======================

    /** 根据 callMode 选 baseUrl。 */
    private String baseUrl() {
        return props.getCallMode() == TerraProperties.CallMode.GATEWAY
                ? props.getGatewayBaseUrl()
                : props.getDirectBaseUrl();
    }

    /**
     * POST form 通用入口:DIRECT 模式补 {@code timestamp + sign};统一解 envelope。
     */
    private JSONObject postForm(String path, Map<String, Object> form, String errorCode) {
        if (props.getCallMode() == TerraProperties.CallMode.DIRECT) {
            form.put("timestamp", System.currentTimeMillis());
            form.put("sign", sign(form, props.getAppSecret()));
        }
        HttpRequest request = HttpRequest.post(baseUrl() + path).form(form);
        String body = exec(request, errorCode);
        return parseEnvelope(body, errorCode);
    }

    /**
     * HMAC-SHA256 签名(占位实现):排序 k=v&k=v(排除 sign),secret 作 key。
     * <p>
     * <b>警告:</b>Terra 真实签名算法未在 API 文档中给出,当前实现参考 garry 内部
     * 常见做法。GATEWAY 模式下不会触发此方法;切到 DIRECT 模式上线前必须向 Terra
     * 团队确认(可能差异:MD5 vs HMAC、排序方式、是否 lowercase、prefix/suffix secret)。
     */
    private static String sign(Map<String, Object> form, String secret) {
        if (secret == null || secret.isBlank()) {
            throw new TerraException("terra_sign_missing", -11,
                    "terra.app-secret is required in DIRECT mode", null);
        }
        TreeMap<String, Object> sorted = new TreeMap<>(form);
        sorted.remove("sign");
        StringBuilder sb = new StringBuilder();
        sorted.forEach((k, v) -> {
            if (sb.length() > 0) sb.append('&');
            sb.append(k).append('=').append(v);
        });
        HMac hmac = SecureUtil.hmac(HmacAlgorithm.HmacSHA256, secret.getBytes(StandardCharsets.UTF_8));
        return hmac.digestHex(sb.toString());
    }

    /** 执行 HTTP,注入超时;非 2xx / IO 异常包成 {@link TerraException}。 */
    private String exec(HttpRequest request, String errorCode) {
        request.setConnectionTimeout(props.getConnectTimeoutMs())
                .setReadTimeout(props.getReadTimeoutMs());
        try (HttpResponse resp = request.execute()) {
            String body = resp.body();
            if (!resp.isOk()) {
                log.warn("{} http {} body={}", errorCode, resp.getStatus(), body);
                throw new TerraException(errorCode, -2, "http " + resp.getStatus(), null);
            }
            return body == null ? "" : body;
        } catch (HttpException e) {
            log.warn("{} io error", errorCode, e);
            throw new TerraException(errorCode, -2, e.getMessage(), null);
        }
    }

    /** 解 Terra envelope {@code {code, message, invokeId, result}};code != 0 抛异常。 */
    private static JSONObject parseEnvelope(String body, String errorCode) {
        JSONObject root = JSON.parseObject(body);
        if (root == null) {
            throw new TerraException(errorCode, -2, "empty response", null);
        }
        Integer code = root.getInteger("code");
        if (code == null || code != 0) {
            throw new TerraException(errorCode,
                    code == null ? -2 : code,
                    root.getString("message"),
                    root.getString("invokeId"));
        }
        JSONObject result = root.getJSONObject("result");
        return result == null ? new JSONObject() : result;
    }

    private static String defaultIfBlank(String v, String dft) {
        return v == null || v.isBlank() ? dft : v;
    }

    private static void sleep(long ms) {
        try { Thread.sleep(ms); }
        catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    }
}
```

### 6.4 异常 `TerraException`

```java
package ink.garry.rd.agent.ws.infra.common.client.terra;

import lombok.Getter;

/**
 * Terra 网关调用异常。统一携带 errorCode(本地错误标签)+ terraCode(Terra 返回 code)+
 * invokeId(Terra 排障字段),便于在应用层根据 terraCode 做差异化处理。
 *
 * <h3>典型 terraCode</h3>
 * <ul>
 *   <li>{@code  0} 成功(不会抛此异常)</li>
 *   <li>{@code -10} 参数错误 / appId 无效</li>
 *   <li>{@code -11/-12/-13} 签名错误 / 签名过期 / 权限错误 — <b>异常监控告警</b></li>
 *   <li>{@code -14} 文件已存在 — 返回前端</li>
 *   <li>{@code -15} 文件名错误 — 返回前端</li>
 *   <li>{@code -16} 文件不存在 — 返回前端</li>
 *   <li>{@code -24/-25} 不支持预览 / 预览生成中 — 返回前端</li>
 * </ul>
 */
@Getter
public class TerraException extends RuntimeException {

    /** 本地错误标签(如 terra_sts_init / terra_get_url_v3 / terra_sign_missing)。 */
    private final String errorCode;

    /** Terra 返回的业务 code,见类注释表。 */
    private final int terraCode;

    /** Terra 返回的 invokeId,排障必备;本地异常为 null。 */
    private final String invokeId;

    public TerraException(String errorCode, int terraCode, String message, String invokeId) {
        super(message);
        this.errorCode = errorCode;
        this.terraCode = terraCode;
        this.invokeId = invokeId;
    }
}
```

## 9. 错误码到业务行为映射

| Terra code | OssClient 行为 | adapter 层建议 |
|---:|---|---|
| `0` | 正常返回 DTO | 200 OK |
| `-10` | 抛 `TerraException(terraCode=-10)` | **告警** + 500;典型是 appId/bucket 配错 |
| `-11/-12` | 抛异常 | **告警** + 500;签名问题需联系 Terra |
| `-13` | 抛异常 | **告警** + 401;凭证失效需重新申请 |

## 10. 安全注意事项

1. **`terra.app-secret` 严禁写进 yml 或 commit**。从 Apollo 注入；本地开发用 `~/.zshrc` `export TERRA_APP_SECRET=...`。
2. **私密桶 SSE-C header 必须透传**给 OSS putObject，否则上传明文文件，下载链接拿不到。前端直传时由 `terra-uploader` SDK 自动处理；后端如果自己 putObject 需手动设置。
3. **预览链接必须加水印**（Terra 文档 §5.1 / §5.3 安全要求）。`FileUrlParam.watermarkJson` 必传，水印内容应能识别到当事人（如 AD 账号 + 部门）。
4. **Content-Disposition / Content-Type 避免 XSS**：不要在 metaData 里允许前端传任意值，对图片/文档强制设置 `attachment` 类型。
5. **STS 凭证 10 分钟失效**，不要在后端缓存；每次申请的 STS 直接透传给前端使用。
6. **下载 URL 默认过期时间** 设 10 分钟（`urlExpire=600000`），按需调整，最大 7 天。
7. **fileId 是敏感引用**：跨用户场景必须做权限校验（adapter 层判断 fileId 是否属于当前 user 的 Skill / Agent / Session），不要把 fileId 直接暴露给非所有者。

## 13. 后续演进

### 13.1 接 Cloudbus 回调（替代轮询）

当文件场景变多（>100 QPS）或需要实时通知后端，把轮询替换为 Cloudbus 订阅：

1. 找 Terra 管理员在 Cloudbus 配 tag 映射：Terra appId(`rd-agent-be`) → Cloudbus appId(`rd-agent-be`)。
2. 订阅事件 `terra-upload-cn@terra_upload_event`（上传成功）+ `terra-upload-corp@terra_upload_fail_event`（上传失败）。
3. 在 adapter 加 `TerraUploadEventListener`，收到 `type=20` 更新业务侧文件状态，`type=11` 触发重传通知。

`OssClient` 接口不变，只是 `waitForUploadComplete` 调用方收敛到一个 Listener。

### 13.2 大文件支持（tus）

引入 `io.tus.java.client:tus-java-client`，新增 `OssClient.requestTusToken(...)`（返回 uploadURL + token + fileId），前端 / 后端选 tus SDK 上传。**仅在出现 > 1G 文件场景时再引入**。

### 13.3 同步到其他区域

`/file/sync` 当前 Terra 已不再提供新增同步接入（文档更新记录 2021-05-18），如必须跨区域分发需走 CDN，本方案不涉及。

1. 平台概述

AgentOps 是面向研发团队的企业级 Agent 能力底座与治理平台。它帮助业务团队通过配置快速构建 Agent，将 MCP / Skill / 知识库沉淀为可复用的部门资产，并通过统一的评测体系确保 Agent 和 Skill 的质量可量化、可回归、可规模化。

平台定位

研发团队的 Agent 能力中台——业务团队用配置出 Agent，部门把工具与提示词沉淀为可复用资产，通过统一评测把"能跑"升级到"敢规模化跑"。

1.2 核心模块说明

基础

工作空间

资源归属与协作边界，支持多空间隔离与团队协作。空间管理者可配置角色与成员。

核心

Agent 管理

两种创建方式：配置模式（单页表单）+ A2A 模式（Nacos 自动同步）。支持版本化管理与对外 API 秘钥。规划中 监督者（SUPERVISOR）/ 路由（ROUTER）Agent 类型

资产

Skill 管理

部门 Skill 资产统一目录，支持在线编辑（DIRECT）与 ZIP 上传（UPLOAD）双模式，支持版本对比与回滚。

资产

工具管理

管理 MCP 与 FunctionCall 工具，支持 REMOTE / API_PACKAGE / OPENAPI_SPEC / MANUAL 四种创建模式。

资产

Prompt 中心

提示词模板资产化管理，支持 {{变量名}} 占位语法与统一寻址。规划中 SKILL.md 行级差异对比

资产

模型管理

统一管理大模型接入信息（API Key / Base URL），支持草稿→启用→禁用生命周期。

资产

沙箱管理

代码执行环境管理，对接阿里 OpenSandbox，支持草稿→初始化→在线→下线完整生命周期。

运行

调试台

多轮对话调试入口，SSE 流式输出，支持 ThoughtChain 步骤级 trace 可视化与 Text/JSON 双模式。

质量

评测体系

Skill 评测（人工调试 / 自动评测）+ Agent 评测（四类测试），5 维评分模型，支持种子用例管理。

管理

权限管理

两级角色体系：工作空间级角色（自定义权限）和平台级角色（全局管理），55 个权限点覆盖全部模块。菜单和操作按钮均按实际持有权限过滤显示。

2. 登录与快速入门

2.1 登录

访问平台地址后自动跳转至登录页。使用 GT 账号（garry统一身份认证）一键登录。

图 1：AgentOps 登录页 — 点击"使用 GT 账号登录"即可进入管理后台

登录成功后默认进入工作台。若遇到权限问题，将看到对应的错误页：

图 2：错误页 — 403 权限不足 / 404 页面不存在 / 500 服务异常
提示 已登录用户直接访问 /login 会自动跳转到工作台。
首次登录自动分配角色 新用户首次通过 GT 账号登录时，平台自动分配「普通用户」内置平台角色，该角色具备工作空间的基础管理权限（创建/查看/编辑/删除工作空间）。如需更多权限，请联系平台管理员在「权限管理 → 用户角色」中分配其他平台角色。

2.2 新用户快速入门路径

新用户只需按以下流程操作，即可在 15 分钟内跑通"配置 Agent → 调试台验证 → 运行评测"的完整链路：

1

登录平台并确认工作空间

登录后，在顶栏右侧查看当前工作空间。如果是首次使用，平台会自动将你加入"默认工作空间"。如需创建新空间，进入工作台 → "工作空间"即可。

  • 确保顶栏切换器显示你所在的工作空间。
  • 切换工作空间后，所有资产列表（Agent / Skill / 工具）会自动刷新为当前空间下的内容。
2

确认模型已启用（模型管理）

Agent 配置时需要选用已启用的模型。进入左侧"模型管理"页面，确保至少有一个模型处于"已启用"状态。如无可用模型，可点击"新增"登记模型接入信息。

  • 模型管理统一登记大模型的 API Key、Base URL、模型名等信息。
  • Agent 配置中的模型字段直接引用这里的已启用模型，无需手填密钥。
  • API Key 在数据库中加密存储。
3

创建或同步 Skill（可选）

如果你希望 Agent 拥有特定能力（如查询 Jira、搜索知识库），需要先在"Skill 管理"中创建或同步 Skill。

  • 自建 Skill：支持在线编辑（DIRECT 模式，直接编写 SKILL.md）和上传 ZIP（UPLOAD 模式）两种方式。
  • 同步公司库：点击"同步公司库"，一键拉取公司 Skill 库的最新 Skill。
  • 创建/同步后，需经过发布检查（大小/格式/可用性 3 项检查）并发布，才能在 Agent 挂载列表中出现。
4

配置一个 Agent

在 Agent 管理页面点击 + 新建 Agent，选择"配置模式"后进入单页分区表单。

  • 基本信息：名称（必填）、描述、系统提示词（可从 Prompt 中心选取模板）、温度。
  • 关联模型：下拉选择模型管理中"已启用"的模型。
  • 工具与上下文：横向 Tab 切换，多选挂载已发布的 Skill / 工具，单选关联在线沙箱，配置记忆策略。
  • 点击底部 "保存" 按钮后，Agent 自动发布为 v1.0.0。
单页配置优势 所有配置在一页内完成，无"下一步 / 上一步"跳转。模型 / Skill / 工具 / 沙箱均从对应资产模块下拉关联。
5

在调试台验证 Agent

Agent 发布后，进入"Agent 调试"页面进行实时验证。

  • 步骤 1：在顶部上下文选择器中选择刚创建的"执行 Agent"（必选）。
  • 步骤 2：可选选择"调试 Skill"，若选择则将该 Skill 强制注入本次会话工具集。
  • 步骤 3：在底部 Sender 输入框中输入测试 prompt，按 Enter 发送。
  • 步骤 4：观察 LLM 流式输出（Bubble 气泡）和 Skill 执行步骤链（ThoughtChain）。
  • 步骤 5：每一步的入参 / 出参 / 状态 / 耗时均实时展示，error 步骤红色高亮。
图 3：调试台主界面 — 顶部上下文选择器（执行 Agent + 调试 Skill）+ 中间对话区（Bubble 消息 + ThoughtChain 步骤链）+ 底部 Sender 输入器
输入模式 按 ⌘J / Ctrl+J 可切换 Text / JSON 两种输入模式。选定 Skill 且该 Skill 有 input schema 时会自动切换到 JSON 模式并按 schema 校验。
6

运行评测（可选）

Agent / Skill 调试满意后，可进入评测台进行量化评估。

  • Skill 人工评测：选执行 Agent + 输入任务 + 期望结果 + 判分方式，执行后查看输出对比与判定结果。好用例可保存为种子。
  • Skill 自动评测：配置执行 Agent + 评测 Agent + 5 维评分 + 用例数，自动生成用例并判分，生成报告（总分 / 维度雷达图 / 用例明细）。
  • Agent 评测：从 Agent 详情页"评测"按钮进入，支持四类测试（单元 / 评估 / 轨迹 / 回归）。
7

查看对外接口文档与秘钥

在 Agent 详情页"API 信息" Tab 中，自动生成 4 个标准 API 的 URL + cURL 调用示例。在"秘钥管理" Tab 中创建 API 调用密钥（Bearer Token），可直接发给业务方接入。

  • POST /v1/agents/{agentId}/invoke — SSE 流式调用
  • POST /v1/agents/{agentId}/sessions — 创建会话
  • GET /v1/agents/{agentId}/sessions — 查询会话列表
  • GET /v1/agents/{agentId}/sessions/{sessionId} — 查询会话详情
完整链路总结 确认工作空间 → 新建模型 → 新建 Skill（可选）→ 单页表单新建 Agent → 调试台验证 → 评测台评估 → 对外 API 接入。整个流程均在平台内闭环完成。

3. 工作空间管理

工作空间是平台中所有资产（Agent / Skill / 工具等）的归属边界和协作容器。一个用户可同时归属多个空间，切换空间即切换资产视图。权限控制也以工作空间为粒度。

图 4：工作空间管理 — 创建和管理团队协作空间，设置成员与角色

3.1 创建空间

在工作台进入"工作空间"页面，点击右上角 + 新建空间 按钮：

  1. 填写空间名称（必填，≤64 字符，在可见范围内唯一）。
  2. 填写空间描述（可选，≤200 字符）。
  3. 可选添加初始成员（按工号 / 姓名搜索）。
  4. 点击"创建空间"。创建人自动成为管理员。

3.2 成员管理

在空间卡片菜单中点击"编辑"，打开右侧编辑抽屉：

  • 添加成员：搜索工号 / 姓名 规划中 GCAC 通讯录接通后支持按姓名搜索，当前仅支持按工号搜索，选择加为管理员或成员。
  • 提升/降级：成员可提升为管理员，管理员可降为成员。
  • 移除：将成员从空间中移除。
  • 所有改动点击"保存"后一次性提交生效。
注意 空间至少保留 1 名管理员。当只剩一名管理员时，"降为成员"和"移除"按钮将被禁用。

3.3 切换空间

顶栏右侧提供空间切换器（用户头像左侧）。点击下拉选择目标空间，切换后所有资产列表自动刷新为当前空间的资产。

  • 选中的空间会在卡片列表中高亮显示"当前"标识。
  • 选中状态自动持久化，下次登录默认载入上次选择的空间。

3.4 删除空间

仅管理员可删除空间。删除前需满足：

  • 空间内无资产（Agent / Skill / 工具数量均为 0）。
  • 在确认弹窗中输入完整的确认词：我确认删除 <空间名> 空间。

删除为逻辑删除，数据库记录保留但不再可见。

4. Agent 管理

Agent 管理是平台的核心模块，提供 Agent 的创建、查看、调试、秘钥管理和对外接口文档等能力。平台支持两种 Agent 创建方式：

创建方式说明平台可改
配置模式在平台通过单页分区表单配置出 Agent，挂载 Skill / 工具等。可编辑 / 发布 / 下线
A2A 模式通过 Nacos 注册中心自动发现并同步外部 A2A Agent。只读，信息从 Nacos 同步

4.1 创建 Agent（配置模式）

在 Agent 管理页面点击 + 新建 Agent，选择"配置模式"后进入单页分区表单：

分区 1 — 基本信息

  • 名称：必填，在同工作空间内唯一。
  • 描述：可选，列表与详情页展示用。
  • 系统提示词：必填。支持从 Prompt 中心选择已有模板一键填入，也可手动编辑。
  • 用户提示词：可选。
  • 温度：0.0 ~ 2.0，默认 0.7。

分区 2 — 关联模型

  • 从模型管理的"已启用"模型列表中下拉选择（单选）。
  • 平台自动从模型管理解析接入信息，不再手填密钥。
  • Plan 模式（必填，默认关闭）：开启后 Agent 运行时将启用 Plan 规划能力。

分区 3 — 工具与上下文（横向 Tab 交互）

该区块以横向 Tab 形式组织以下配置：

Tab内容数量
Skills从 Skill 管理多选挂载"已发布"Skill。多选
工具从工具管理多选挂载"已发布"工具（含 MCP / FunctionCall）。多选
沙箱从沙箱管理下拉选择"在线"沙箱。单选（可空）
知识库保留占位，暂未上线。规划中—
记忆长期记忆策略（无 / 向量召回 / 全文召回）+ 短期记忆策略（无 / 最近 N 轮 / 滑动窗口）+ QPS + 日预算。规划中 QPS 与日预算限流单选

每个 Tab 右侧提供 + 添加 按钮，点击弹出对应资产选择器。

提交

表单底部固定三个按钮：取消 / 保存草稿 / 发布。保存成功后 Agent 自动发布为 v1.0.0，状态变为"在线"。

4.3 版本管理

配置模式 Agent 采用 草稿 → 发布 → 不可变历史快照 的版本化机制：

  1. 在"版本管理" Tab 右上角点击 + 创建版本，基于当前在线版本生成草稿。
  2. 在版本列表的 DRAFT 行点击 "编辑"，进入全页分区表单修改配置。
  3. 修改完成后点击 "保存草稿"，系统自动保存并跳回版本管理 Tab，方便继续查看版本列表或发布。
  4. 在版本管理 Tab 点击 "发布"，选择影响等级（patch / minor / major）并填写变更说明（≥10 字）。
  5. 发布后版本号自动递增（Semver），历史版本只读保留。
影响等级何时选递增规则
patch提示词文字微调 / 温度调整v1.0.3 → v1.0.4
minor加挂/解绑 Skill / 改 QPSv1.0.4 → v1.1.0
major模型大换 / 不兼容变更v1.1.0 → v2.0.0

历史版本支持查看快照。规划中 版本对比与回滚

4.4 秘钥管理

每个 Agent 可创建多个 API 调用密钥（Bearer Token），供外部系统通过 Open API 调用该 Agent。

  • 创建密钥：点击"创建密钥"，填写备注（可选），生成后只展示一次明文，请立即保存。
  • 查看密钥：列表中的密钥均脱敏展示（如 sk-abc****def）。
  • 明文查看：点击"查看"，需二次确认，操作记录写入审计日志。
  • 删除密钥：逻辑删除，立即失效。
安全提醒 密钥创建后仅展示一次明文，请妥善保存。密钥泄漏请立即删除并创建新密钥。

5. Skill 管理

Skill 管理是部门 Skill 资产的统一目录与评测入口。每个 Skill 既可部门自建，也可一键同步公司 Skill 库。

图 6：Skill 管理列表 — 支持创建、同步公司库、发布检查与评测

5.1 创建 Skill

在 Skill 管理页面点击 + 新建 Skill。Skill 支持两种创建模式：

模式适用场景操作方式
DIRECT（在线编辑）简单 Skill，直接在浏览器中编写填写前部元数据 + 在线 Markdown 编辑器编写 SKILL.md
UPLOAD（ZIP 上传）复杂 Skill，含多个资源文件上传 .zip 包（≤2MB），解压后根目录必须含 SKILL.md

DIRECT 模式下，编辑器分为"前部元数据"、"SKILL.md 编辑"和"资源文件管理"三个区域：

  • 元数据：skillId（对外唯一标识，slug 风格）、名称、Semver 版本号、标签。
  • SKILL.md：Monaco 编辑器在线编写，自动从首段抽取描述。
  • 资源文件：文件树面板 + 内容编辑区，支持添加/删除/重命名文件。

发布检查

点击"发布"时，系统自动执行三项检查：

  1. 大小检查：SKILL.md 不超过 1MB，总资源文件不超过 10MB。
  2. 格式检查：SKILL.md 的 YAML 前部元数据解析是否合法。
  3. 可用性检查：运行时验证 Skill 能否正确加载。

检查通过后 Skill 变为"发布"状态；未通过则显示"检查失败"及具体错误信息。

5.2 同步公司库 规划中

点击顶部 "同步公司库" 按钮，平台自动拉取公司 Skill 库的最新 Skill 并增量入库：

  • 同步完成后弹出结果 Modal，显示新增 X 个、更新 Y 个、无变化 Z 个。
  • 同步过来的 Skill 标记为"公司库"来源，本地只读不可改；如需修改请点击"fork 为自建"生成本地副本。

规划中 当前版本公司库同步功能暂不实现，接口已下线。后续版本恢复后本章节将生效。

5.3 Skill 状态与版本管理

Skill 生命周期：草稿 → 检查中 → 检查失败 → 发布（在线） → 弃用。

  • 草稿：仅作者可见，不影响调试台 / 评测台 / Agent 挂载。
  • 检查中 / 检查失败：发布检查流程中的中间状态。
  • 发布：Skill 上线，可被调试台调用、被 Agent 挂载。
  • 弃用：Skill 不再出现在下拉列表中，但历史版本仍可只读查看。

Skill 详情页包含 4 个 Tab：

Tab内容
基本信息名称 / skillId / 描述 / 标签 / 来源 / 当前版本 / 复用数。
资源文件文件树（可展开/折叠）+ 文件内容预览。
检测记录每次发布检查的历史记录，包含检查结果和错误详情。
版本管理版本历史列表，支持版本对比与回滚。

5.4 版本对比与回滚 规划中

在版本管理 Tab 中选择两个历史版本进行对比，展示字段级差异（名称 / 描述 / 标签的 onlyA / onlyB / 差异项）。规划中 SKILL.md 行级差异对比和后端对比接口暂未实现。

10. 调试台

调试台（Agent 调试）是业务方对 Agent / Skill 的"可点可看可演示"入口——选定执行 Agent，可选定调试 Skill，发起多轮对话，并在每次执行中可视化每一步 Skill 调用的入参 / 出参 / 状态 / 耗时。规划中 Fixtures 库

10.1 发起对话

  1. 选择执行 Agent（必选）：从下拉列表选择当前工作空间内可见的 Agent。切换 Agent 时若当前会话有消息，系统提示将开启新会话。
  2. 选择调试 Skill（可选）：下拉首项为「不限（Agent 自主决策）」。选定特定 Skill 后，该 Skill 将被强制注入本次会话的工具集。
  3. 输入消息：在底部 Sender 输入框中输入文本，按 Enter 发送（Shift+Enter 换行）。
  4. JSON 模式：按 ⌘J / Ctrl+J 快捷键切换到 JSON 模式，可输入结构化 JSON 并按 Skill input schema 校验。
  5. 查看回复：LLM 输出以 SSE 流式方式逐字渲染到消息气泡中。消息支持复制 / 重新生成。

10.2 会话管理

会话列表通过顶部 SubToolbar 的会话胶囊管理（如「📂 当前会话标题 · N turns」），点击下拉可切换 / 重命名 / 删除 / 新建会话。每次 invoke 调用自动关联当前会话，多轮对话上下文保持。

10.3 步骤级 Trace

当 Agent 调用 Skill / 工具时，调试台以 ThoughtChain 步骤链可视化整个执行过程：

  • 每步展示：步骤名 / 入参 / 出参 / 状态（pending / success / error）/ 耗时 ms。
  • 入参/出参默认折叠，点击展开查看完整 JSON。
  • error 状态步骤以红色边框高亮 + 内嵌错误消息，不阻塞后续步骤渲染。
  • 步骤链顶部展示 trace_id，可复制用于后端排查。

10.4 异常处理

场景处理
未选 AgentSender 禁用 + 顶部 Alert "请先选择执行 Agent"。
JSON 模式校验失败Sender 禁用 + 编辑器底部红色错误提示（行号 + 原因）。
SSE 中断"重试"按钮可见；已渲染步骤保留。
流式输出中Sender 显示 loading + 中止按钮。

11. 评测体系

评测体系是平台的"质量哨兵"，提供 Skill 评测和 Agent 评测两大模块，覆盖人工评测与自动评测两种模式。

图 11：评测任务列表 — 展示所有评测任务的状态与进度

11.1 Skill 人工评测

从 Skill 列表行操作点击"评测"进入评测台，切换到「人工评测」Tab：

  1. 选择执行 Agent：下拉选择，可选"空白沙盒 Agent"（系统内置，模型配置最经济，提示词为空）。
  2. 输入任务：填写测试任务内容。
  3. 填写期望结果（可选，"不判分"模式时可留空）。
  4. 选择判分方式：LLM Judge（用评测 Agent 判分）/ 关键词匹配 / 不判分。
  5. 点击"执行"，系统同步调用 Skill 并展示实际输出。
  6. 输出对比区展示实际输出 vs 期望结果，以及自动判定结果（通过/不通过 + 分值 + 时延）。
  7. 可将好用例"保存为种子"，回流到自动评测的数据源。

11.2 Skill 自动评测

切换到「自动评测」Tab，配置并执行批量评测：

  1. 执行 Agent：选择用于执行 Skill 的 Agent。
  2. 评测 Agent：选择用于判分的 LLM Judge Agent。
  3. 评测维度：勾选评分维度——准确性 / 相关性 / 完整性 / 风格一致 / 安全合规（5 维）。
  4. 用例数量：默认 20 条，范围 1~500 条。
  5. 数据来源：Skill 描述自动生成 / 历史样本 / 种子用例。
  6. 点击"生成并执行评测"，系统自动生成用例 → 异步执行 → 判分 → 生成报告。
5 维评分模型 准确性（关键事实与预期一致）/ 相关性（是否回答了输入）/ 完整性（是否覆盖所有要点）/ 风格一致（语气/格式）/ 安全合规（无敏感/违规内容）。

11.3 Agent 评测

从 Agent 详情页顶部"评测"按钮进入 Agent 评测台，支持四类测试类型：

测试类型测什么判分方式
单元测试（UNIT）单点能力是否达标关键词 / 规则
评估测试（QUALITY）LLM 输出质量 + 多轮连贯性评估 Agent 5 维打分
轨迹测试（TRAJECTORY）多步骤行为合理性（工具/子 Agent 调用）轨迹规则 + 评估 Agent
回归测试（REGRESSION）行为稳定性（跨版本对比）与基线报告逐项对比

Agent 评测采用两阶段流程：

  1. 阶段一：构建测试用例集（自动生成 / 手动导入 规划中 / 复用已有）。
  2. 阶段二：执行评估任务（配置被测 Agent + 评估 Agent + 维度 + 并发数 → 逐用例执行 → 评估 Agent 判分 → 生成报告）。

11.4 种子用例管理

种子用例（Golden Test Cases）是经过人工验证的高质量测试用例，可回流到自动评测数据源，持续提升评测准确性。

  • 保存种子：在人工评测结果中，点击"保存为种子"，将 input / expectedOutput 保存至种子库。
  • 管理种子：评测台"种子库"页面查看 / 删除某个 Skill 下的种子用例。
  • 复用种子：自动评测的数据源支持选择"种子用例"，优先使用种子数据生成评测。

11.5 评测报告与版本对比

评测报告内容

  • 概览：总分 / 通过率 / 平均时延 / 用例数 / 被测版本号 / 评测模式。
  • 5 维雷达图：评估 / 轨迹测试展示维度得分雷达图。
  • 用例明细：每条 input / actual / expected / 判定 / 维度分 / 时延 / traceId。
  • 轨迹明细（轨迹测试）：每步思考 / 工具调用 / 参数 / 子 Agent / 观察，标注合理性。
  • 支持导出 CSV。规划中

版本对比 规划中

选择两次评测报告进行对比，展示：

  • 总分差 / 通过率差 / 时延差（正负彩色标注）。
  • 维度差异表：每项标注趋势（↑ 提升 / ↓ 回退 / — 持平）。
  • 逐用例对比标注"回退 / 持平 / 提升"。

13. 系统设置

系统设置位于工作台一级页面，提供平台级的全局配置管理。入口仅对持有对应权限的用户显示。

13.1 系统模型管理

系统模型是全平台共享的大模型配置，与工作空间无关，一次配置全平台所有空间的 Agent 均可引用。

所需权限 访问系统设置 → 模型管理，需持有 system:model_read（查看）或其他 system:model_* 权限。

15. 常见问题

Q1：为什么 Agent 配置中模型下拉为空？

请先到模型管理中登记模型并设为"已启用"状态。Agent 配置中的模型下拉仅展示已启用的模型。如已有模型仍不可见，请确认其状态不是"草稿"或"已禁用"。

Q2：为什么我创建的 Skill 在 Agent 挂载列表中看不到？

Skill 必须处于"已发布"状态才会出现在 Agent 挂载的下拉列表中。请在 Skill 列表中将该 Skill 发布。如发布检查失败，请查看检查记录中的错误详情。

Q3：A2A 模式的 Agent 可以编辑吗？

不可以。A2A Agent 的所有字段以 Nacos 为唯一权威源，平台只读展示。您可以在详情页点击"手动重新同步"拉取最新信息。如需修改，请到 Nacos 端变更配置。

Q4：如何对比同一 Agent 两个版本的效果？

进入 Agent 详情页的"版本管理" Tab，选择两个历史版本点击"对比"，或进入评测报告页面选择两次评测报告进行对比。

Q5：调试台 SSE 连接中断怎么办？

已渲染的消息和步骤会保留。点击 Sender 中的"重试"按钮，系统将从最后一条用户消息重新发送。

Q6：如何删除一个工作空间？

需满足两个条件：空间内无资产（Agent / Skill / 工具数量均为 0）；在删除确认弹窗中输入完整确认词。删除为逻辑删除，数据库记录保留。

Q7：Prompt 中心的 {{变量名}} 是如何工作的？

平台负责存储和展示模板原文。编辑时系统自动识别 {{变量名}} 并展示变量清单。变量的实际替换由调用方在运行时完成。

Q8：评测的"空白沙盒 Agent"是什么？

系统内置的一个轻量 Agent，模型配置为最经济选项，提示词为空。它专为 Skill 评测设计——评测时 Skill 会被动态注入为其工具集，无需为每次评测创建专属 Agent。

Q9：API Key 泄漏了怎么办？

请立即在 Agent 详情页"秘钥管理" Tab 中删除泄漏的密钥，并创建新密钥。密钥删除后即刻失效。平台会对密钥查看操作记录审计日志。

Q10：为什么我在某个页面看到"无权访问"？

请确认当前登录的工作空间是否正确（顶栏右侧切换器）。如工作空间正确，请联系空间管理员在"角色管理"中为您的账号分配所需权限。操作失败时系统会显示具体缺少哪个权限（如"缺少 agent:create 权限"），可据此向管理员申请。

Q11：首次登录后为什么看不到左侧导航菜单？

首次登录自动分配的「普通用户」角色仅含工作空间基础管理权限，不含 Agent / 模型等资产模块权限。因此左侧导航中与这些模块对应的菜单不会显示。请联系平台管理员为您分配适合您工作的平台角色，或由空间管理员将您加入工作空间并赋予空间角色。

## 何时创建一份 plan

满足以下任一条件就应该创建 plan:

- 涉及 3 个以上文件的修改
- 跨越 2 次以上对话的工作(agent 中途会被换出)
- 任何架构层面的改动
- 任何会引入新依赖的工作
- 任何耗时超过 30 分钟的任务

## Plan 模板

新建 plan 文件时建议格式:

```markdown
# <Plan 标题>

**创建日期:** YYYY-MM-DD
**负责人:**
**状态:** active / blocked / completed

## 目标

<一句话说清楚要达成什么>

## 上下文

<为什么现在做、相关背景。如果对应 PRD 的某一节,在这里链接>

## 步骤

- [ ] 步骤 1
- [ ] 步骤 2
- [ ] 步骤 3

## 决策日志

<执行过程中的关键决策。每条注明日期>

## 完成标准

<怎样算"完成"。UI 改动建议加上"在浏览器跑通主流程">
```
